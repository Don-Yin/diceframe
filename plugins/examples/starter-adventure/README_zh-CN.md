# 灯火港湾：冒险作者示例

[English](README.md) | 简体中文

这是基于当前契约的原创**引导式**示例：包含码头、灯塔两个可游玩场景、
互斥分支、GM 私密参考结局与线索、世界模板、独立资料册和双地点关系地图。
不包含脚本、执行入口、自动战斗或物品奖励。依赖声明中的 `core:dnd2024`
版本 1 是规则运行时契约号，不是应用版本号。示例故事和数据沿用本仓库的
AGPL-3.0 许可证，全文见 LICENSE；没有第三方剧本文字或图片。

在主仓库根目录执行：

```sh
python scripts/validate_content_module.py plugins/examples/starter-adventure --json
python scripts/package_plugin.py plugins/examples/starter-adventure
python -m pytest tests/test_starter_adventure_conformance.py -q
```

在内容包页面导入生成的 `.dfplugin` 并启用，然后在冒险库选择“灯火港湾”开局，
保留其明确的包来源。catalog 模式提供已安装来源，不自动复制到你的个人内容。
世界与 **Harbor Keeper Notes** 资料册是两个资源：世界提供背景和默认关系地图，
需要资料册中的参考内容时，在本局资料来源中选择它。

GM 可以查看私密参考结局；玩家只收到公开投影，私密选项不会进入玩家选择列表。
公开选项会打开公开结局。参考结局给 GM 提供引导文字，不宣称自动演完整个故事。

复用时复制整个目录，同时修改包 ID 与目录名。为冒险和资源设置自己的稳定 ID，
更新声明路径、地图/世界引用和语言文件的 target。改标题不会产生新身份。
针对计划支持的主程序修订，校验源目录和实际生成的压缩包；保留来源授权与变更说明。
不要静默替换已发布版本的内容，也不要绕过被存档引用时的更新阻断。
