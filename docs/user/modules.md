# 内容包与冒险使用指南

最新界面流程见[内容与游玩](../zh/content-and-play.md)（[English](../en/content-and-play.md)）。

DiceFrame 把可玩的冒险和提供这些内容的来源分开呈现。导航中的 **内容库**（`/library`）用于浏览已发现的冒险、查看来源和规则要求，并从可用冒险进入创建流程；**内容包**（`/modules`）用于安装、更新、禁用、卸载内容包，以及查看包内的资源和版本。

- **内容包**：安装到 DiceFrame 的完整来源包，可以提供一个或多个冒险，以及可复用的 NPC、怪物、物品、遭遇、地图和场景资料。
- **冒险**：带有剧情图、场景和可选遭遇的可玩内容。内容库中的“用此冒险开局”会把所选冒险及来源身份交给创建页；最终规则和世界兼容性仍由创建页与服务端校验。
- **资源库**：内容包内供冒险引用的 NPC、物品、遭遇、地图等资料；只有提供冒险的内容包才会在模组与冒险列表中形成开局入口。

安装内容包不会修改已有存档，也不会把整包内容一次性塞入 AI 上下文。DiceFrame 会按当前场景、地点、角色、冒险和世界状态取用所需资料。

## 浏览冒险和管理内容来源

1. 在导航中打开 **内容库**，按来源或规则筛选冒险；详情只展示目录元数据，不读取原始包文件。
2. 选择可用冒险后进入创建页。创建页会再次检查来源身份、规则运行时、冒险格式和世界策略。
3. 需要安装或管理内容包时，选择内容库中的 **管理来源**，或直接打开导航中的 **内容包**（`/modules`）。

## 安装本地内容包

1. 在 **内容包** 页面“导入本地模组”选择 `.dfplugin` 文件。
2. 选择“预览安装影响”。
3. 阅读阻断项与警告；有阻断项时不要安装。
4. 确认没有阻断项后选择“安装模组”。

预览会检查内容包的格式、DiceFrame 版本要求、规则运行时和冒险兼容性。安装成功后可在内容来源列表打开详情，查看其冒险、资源数量、兼容性和正在使用它的存档。

## 自动化等级

- **参考**：提供剧情、场景与资料；GM 或 AI GM 仍需裁定较多细节。
- **引导**：提供冒险流程、部分目标和遭遇的结构化指引。
- **确定性**：关键遭遇、规则引用、世界状态、目标与里程碑可由 DiceFrame 的既有规则和世界系统更严格地处理。

自动化等级不会让模组获得规则执行权；规则判定仍由所选规则运行时负责。

## 规则运行时与版本

当前内置注册表提供 `core:legacy` 和 `core:dnd2024` 两个运行时；D&D 2024 使用专用的 `core:dnd2024` runtime。`core:legacy` 是兼容旧规则路径的适配器，不能在内容包说明中当作完整的 D&D 2014 规则实现。内容包声明的 `required_runtime`、最低版本和冒险格式必须与创建页选择的运行时匹配；DiceFrame 不会把不同 runtime 静默当作兼容，也不会自动把 2014 与 2024 的数值或机制互相转换。

## Homebrew、Foundry 与 PDF

Homebrew 可以作为数据模组提供，并按内容类型交给 DiceFrame 的相应系统处理。它不会因为被导入就获得规则执行权。

冒险创作页的“导入剧本 / 外部模组”目前支持受限的本地导入：Markdown/TXT、Foundry Adventure 文档 JSON、未加密 Fantasy Grounds XML/`.mod`，以及有文字层的 PDF。Foundry 适配器读取 Adventure 导出中的 journal、actors、items、scenes；它不等于 LevelDB 合集、整个系统或通用模组安装器。PDF 只提取文字层；扫描件需要先 OCR，附件、动作和外部图片不会被执行或自动下载。

这些输入先生成仅 GM 可见的 Draft，作者必须编辑资源和引用、重新审核并确认保存，才会成为本地原生冒险包。外部 HP、AC、攻击、奖励等数值保留为参考原文，不会自动转换成 DiceFrame 机制；未知引用可保留为文字，未解析的规则不会直接变成可运行内容。

## 为什么不能更新、禁用或卸载？

当已有存档绑定了某个模组中的冒险时，DiceFrame 会阻止会改变该内容的更新、禁用或卸载，并显示受影响存档。这样可以保证下次打开或重开存档时，看到的仍是同一版本的冒险内容。

若要处理这些操作，先在模组详情的“使用中的存档”确认范围；不要通过删除文件绕过保护。

## 隐私与秘密

模组与冒险可标注公开或 GM 私密内容。普通玩家不会从冒险面板或游戏 API 获得 GM 私密节点、目标、章节，或指向隐藏节点的线索。秘密成为公开信息时，应由游戏中的明确状态与叙事流程处理。
